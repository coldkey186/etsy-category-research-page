Etsy Category Research Helper

Internal Etsy Open API v3 research proof tool.

About this application

Etsy Category Research Helper is an internal seller research tool used to test Etsy Open API v3 for category taxonomy and active listing market signals.

The application is designed to help compare Etsy category options using permitted API data such as taxonomy nodes, listing samples, price ranges, and aggregate competition indicators.

Current status

This application is currently for internal testing only. It is not a public commercial product.

Data use

  • Does not edit Etsy listings.
  • Does not read sales data.
  • Does not send email.
  • Does not scrape Etsy pages.
  • Does not automate buyer or seller actions.
  • Does not collect passwords or payment information.
